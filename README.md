# GourmetScale

**A cozy kitchen companion for precision recipe scaling.**

GourmetScale is a browser-based recipe scaler designed to help home cooks resize recipes with confidence. It pairs ingredient scaling with practical culinary guidance in a warm, responsive interface.

## Competition context

This project was developed for the **ZEROCODE – AI-Assisted Web Development** event at **Techfest, IIT Bombay**. It secured **1st place among 300 participants in the zonal round**, earning eligibility for the national round.

## Features

- **Recipe scaling:** enter a dish, its original serving count, and the target serving count.
- **Dynamic ingredients:** add ingredients and scale quantities proportionally.
- **Visual scaling feedback:** a live multiplier and proportion gauge make the adjustment easy to understand.
- **Culinary guidance:** contextual cookware, seasoning, and timing insights help account for practical cooking considerations.
- **Recipe management:** save recipes, view cookbook history, copy recipe details, and export results.
- **Kitchen experience:** responsive layout, light/dark theme controls, toast feedback, and optional audio interaction.
- **Built-in checks:** includes an in-app judge/test interface for checking key behaviours.

## Tech stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox, animations)
- Vanilla JavaScript (ES6+)
- No external runtime libraries or build step

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a modern browser.

The app is designed as a static front-end project and does not require a package manager or development server.
